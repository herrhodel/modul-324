# DevOps

DevOps verbindet Entwicklung (Development) und Betrieb (Operations). Ziel ist es,
Software schneller und zuverlässiger auszuliefern, indem beide Seiten
zusammenarbeiten und möglichst viele Schritte automatisiert werden (Build, Test,
Deployment, Monitoring).

- Kurze Feedback-Schleifen: Fehler werden früh bemerkt.
- Automatisierung statt manueller, fehleranfälliger Schritte.
- Gemeinsame Verantwortung für Entwicklung und Betrieb.
- Kontinuierliche Verbesserung.

Die Themen dieser Seite (Versionskontrolle, Paketmanager, Testautomation,
CI / CD) sind die Bausteine dieses Kreislaufs.
